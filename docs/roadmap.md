# 스트레이트! 개발 로드맵

목적: 게임성 강화 — 특히 "상대와의 상호작용 부족"을 해결하고 재방문 동기를 만든다.
마지막 갱신: 2026-10-03

## 진행 중

- **구글 로그인 · 부분 유료화 · 그랜드마스터 · 숨은 기록/밸런스 데이터**
  스펙: `docs/superpowers/specs/2026-10-02-account-monetization-design.md`

## 확정 (다음 순서)

1. **상대 진행도 표시 + 직전 선언** — 구현 완료(2026-10-03, 브랜치 `feat/ready-callout`, 로그인 브랜치 위). 상대 칸에 2/5부터 표시, 4/5에 🔥 칩·로그·효과음.
   - 상대 칸에 가장 긴 스트레이트 진행도(예: 핑크 3/5)를 작게 표시.
   - 누군가 4/5가 되면 로그·효과음으로 자동 선언 → 견제 플레이 유도.
   - 선언 문구: **"레디!"** — 예: `🔥 수달 레디! (핑크 4/5)`
2. **데일리 챌린지**: 매일 모두에게 같은 카드 배치, 최소 턴으로 스트레이트 완성 경쟁 + 순위표. (로그인 필요)
3. **온라인 편의 기능**: 같은 멤버로 바로 다시 하기, 빠른 매칭, 끊긴 사람 재접속.
4. **온라인 도중 퇴장 대응** (현재: 나간 사람 차례가 오면 게임이 멈추고, 방장이 나가면 AI도 멈춤)
   - 방 공용 턴 마감 시간: 마감이 지나면 남은 사람의 기기(방장 우선)가 대신 처리(2장 뽑고 턴 넘김).
   - AI 대리: 2번 연속 시간 초과 또는 항복 → 그 자리를 **쉬움 AI**가 이어받음, 로그 표시.
   - 방장 승계: 방장이 나가면 다음 자리가 방장 역할(AI 턴·마감 처리) 승계.
   - 재접속 복귀: 같은 계정으로 돌아오면 자리 회수.
   - 어뷰징 방지: AI가 **3턴 이상** 대신 둔 판은 원래 주인에게 무조건 **탈주 패배**(AI가 이겨도), 업적 진행 미반영. 시간 초과 1번 → 다음 턴 **30초**, 그 다음부터 **15초**. 탈주 횟수는 숨은 기록(랭크전 감점·매칭 후순위용).
   - 사람이 혼자 남으면 AI 상대로 계속, 이기면 정상 승리.

## 향후 계획

- **랭크전**: 실력 점수(ELO 계열)로 오르내리는 경쟁 등급, 시즌제·시즌 보상(꾸미기).
- **레벨 시스템**: 플레이할수록 쌓이는 경험치 기반 성장 지표. 내려가지 않는다.
  - 레벨 ≠ 랭크: 레벨은 "얼마나 많이 했나"(누적·단조 증가), 랭크는 "얼마나 잘하나"(승패로 오르내림·시즌 초기화).
- 위 두 기능의 재료가 되는 계정 전적(승/패/무승부/판수)은 로그인 작업 때부터 숨은 기록으로 쌓는다.

## 사용자 확인 대기

- **어려움 AI가 견제할 때 상대 손패를 참고하는 것**(2026-10-02 기준 유지): 사용자가 직접 플레이해 본 뒤 괜찮은지 판단하기로 함. 몇 판 해 본 뒤 적당한 때에 다시 물어볼 것. 바꾸게 되면 공개 정보(점수덱·바닥)만으로 판단하도록 수정.
