# 계정 · 부분 유료화 설계 (작성 중)

상태: **섹션 1·2 확정, 섹션 3(업적 최종 보상) 미확정, 첫 출시 유료 아이템 목록 미정.**
첫 출시 목록은 Firebase 콘솔에 로그인 가능한 PC에서 작업할 때 정한다.

## 하위 프로젝트

| 순서 | 내용 | 상태 |
|---|---|---|
| A | 구글 로그인 + 진행도 클라우드 저장 | 설계 확정, 미구현 |
| B | 개발자 계정 전체 해금 | 설계 확정, 미구현 |
| C | 부분 유료화 (꾸미기 + 멤버십) | 설계 확정, 결제는 후속 단계 |
| D | 업적 전체 클리어 최종 보상 | 미확정 |

## 섹션 1 — 로그인과 데이터 (확정)

- **구글 로그인 필수.** 로그인 전에는 게임 진입 불가. 첫 로그인 때 닉네임 설정(구글 이름 기본값).
- **Firebase Auth(Google provider)** 사용. 지금의 Firebase 프로젝트 `straight-game` 그대로.
- **`users/{uid}`**: 통계·해금·장착·설정. 본인만 읽기/쓰기. 판 종료 시와 꾸미기 변경 시에만 저장(쓰기 횟수 절약). localStorage는 계정별 캐시로만.
- **`entitlements/{uid}`**: 본인은 읽기만, 쓰기는 콘솔(운영자)·추후 서버만.
  - `role: "dev"` → 모든 유료·무료·멤버 아이템 사용 가능 + VIP 배지 표시
  - `items: [...]` → 구매한 영구 아이템 id
  - `membershipUntil` → 멤버십 만료 시각
- **기존 진행도 이관 없음.** 계정 데이터가 유일한 기준. "기존 플레이어는 전부 해금" 규칙 제거.
- **카카오톡 등 인앱 브라우저**는 구글 로그인이 막히므로 감지해 "Chrome/Safari로 열기" 안내.
- **온라인 방 규칙**을 "로그인한 사용자만"으로 강화.
- 콘솔 작업(사용자): Google 로그인 제공자 사용 설정, 승인 도메인에 `emalration2-sketch.github.io` 추가, 보안 규칙 게시, 개발자 계정 `entitlements/{uid}.role = "dev"` 지정.
- 한계: 통계는 클라이언트가 기록하므로 업적 진행도 위조는 막을 수 없다. 유료 권한은 서버만 쓸 수 있어 안전하다.

## 섹션 2 — 부분 유료화 (확정)

**원칙**: 게임 플레이 100% 무료. 유료는 꾸미기뿐. 기존 업적 보상은 계속 무료.

| 상품 | 가격 | 방식 |
|---|---|---|
| 유료 테두리 | 개당 2,200원 | 영구 |
| 유료 패턴 | 개당 2,200원 | 영구 |
| 유료 테마 | 개당 3,300원 | 영구 |
| 멤버십 | 3,300원 / 30일 | 기간제, 기간 중 재구매 시 남은 기간 + 30일 |

- 칭호·BGM·캐릭터는 개별 판매하지 않는다.
- **멤버십 혜택**: (1) 판매 중인 모든 유료 아이템 사용, (2) 멤버십 전용 테마와 멤버십 전용 캐릭터, (3) 닉네임 태그 옆 VIP 배지.
- 멤버십 전용 테마는 **내 화면에만** 적용(다른 플레이어에게 강제하지 않음).
- **멤버십 만료 시** 멤버십으로 쓰던 아이템(유료·멤버 전용)은 기본 아이템으로 자동 해제.
- **구매 위치**: 수집품 각 탭에 유료 아이템을 가격과 함께 표시하고 거기서 구매.
- **결제는 후속 단계**: 토스페이먼츠/포트원 + Cloud Functions(Blaze 요금제) 결제 검증 → `entitlements` 기록. 사업자등록·통신판매업 신고·이용약관·개인정보처리방침·환불 정책(디지털 콘텐츠 청약철회 제한 고지)·미성년자 결제 안내 필요.

**이미 구현된 것** (커밋 `6384994`): 멤버십 전용 테마 3종(그린 펠트·월넛 테이블·블랙 마블), 수집품 "테마" 탭, VIP 배지. `hasMembership()`은 로그인 전까지 로컬 개발 서버에서만 true인 임시 판정.

## 섹션 3 — 업적 전체 클리어 최종 보상 (미확정)

검토 중인 안은 대화 기록 참조. 확정되면 여기에 기록.
