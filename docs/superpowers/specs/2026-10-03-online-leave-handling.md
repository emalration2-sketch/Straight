# 온라인 도중 퇴장 대응 (2026-10-03)

로드맵 4번의 확정 규칙을 구현 단위로 옮긴 문서. 서버(Cloud Functions) 없이 방 문서(`rooms/{code}`)와 클라이언트만으로 처리한다.

## 문제

- 나간 사람 차례가 오면 그 사람 기기의 타이머만 돌기 때문에 게임이 멈춘다.
- AI 차례는 방장(자리 0)만 진행하므로 방장이 나가면 AI도 멈춘다.

## 규칙 (로드맵 확정안)

| 항목 | 동작 |
|---|---|
| 공용 턴 마감 | 턴이 넘어갈 때 방 문서에 `turnDeadline`(절대 시각 ms)을 기록. 사람 60초, AI 20초. |
| 시간 단축 | 그 플레이어의 시간 초과 누적 1번 → 30초, 2번 이상 → 15초. |
| 대신 처리 | 마감 + 5초가 지나도 턴이 그대로면 남은 사람 기기가 대신 처리(사람 턴 = 2장 뽑고 넘김, AI 턴 = AI 진행). 순서: 방장 → 자리 순, 사람마다 5초 간격. 트랜잭션으로 한 기기만 처리(`claimSeq`). |
| AI 대리 | **2번 연속** 시간 초과 또는 온라인 **항복** → 그 자리를 **쉬움 AI**가 이어받음(`aiTakeover`), 로그 표시. |
| 방장 승계 | 멈춘 AI 턴을 대신 처리한 기기가 방장(`hostIndex`)이 된다. 방장 = AI 진행·밸런스 기록 담당. |
| 재접속 복귀 | 같은 구글 계정(`uid`)으로 같은 방 코드에 다시 들어오면 자리를 돌려받는다(AI 대리 해제). |
| 어뷰징 방지 | AI가 **3턴 이상** 대신 둔 자리의 주인은 결과와 상관없이 **탈주 패배**, 업적 진행 미반영. 숨은 기록 `record.leaves` +1. |
| 혼자 남음 | AI 상대로 계속, 이기면 정상 승리. |

## 데이터

- 방 문서: `turnDeadline`(number), `hostIndex`(number, 기본 0), `claimSeq`(number, 마지막으로 대신 처리한 `turnSeq`).
- 플레이어: `uid`(string|null), `timeouts`(누적), `timeoutStreak`(연속), `aiTakeover`(bool), `aiTurns`(AI가 대신 둔 턴 수). 모두 `sanitizeRoomData`에서 숫자/불리언/길이 제한으로 정리.

## 테스트 도구 (로컬 전용)

- `?seat=N` — 같은 브라우저에서 다른 기기처럼 접속(clientId에 접미사).
- `?fast` — 제한 시간 1/6(사람 10초, AI 4초 등)로 빠르게 확인.
