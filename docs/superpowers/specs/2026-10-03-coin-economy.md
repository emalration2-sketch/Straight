# 코인 경제 (2026-10-03, 제안 단계 — 구현은 결제 작업과 함께)

재화 이름 **코인**. 아이콘은 금화(C1)에 "S" 대신 프리즘(`COIN_SVG`, 챌린지 보상 표시에 이미 사용 중).
멤버십은 **코인으로만** 구매한다. 무료로 코인을 얻는 곳은 출석과 챌린지 두 곳뿐이다.

## 충전 패키지 (기준: 1,100원 = 110코인, 10원 = 1코인)

| 가격 | 코인 | 보너스 | 1,000원당 코인 |
|---|---|---|---|
| 1,100원 | 110 | 0% | 100.0 |
| 3,300원 | 345 | +4.5% | 104.5 |
| 5,500원 | 605 | +10% | 110.0 |
| 11,000원 | 1,265 | +15% | 115.0 |
| 33,000원 | 3,960 | +20% | 120.0 |
| 55,000원 | 6,875 | +25% | 125.0 |

보너스는 단계마다 5%씩 커진다(사용자 확정 2026-10-03, 3,300원은 깔끔한 숫자로 345). 1,000원당 코인이 단계마다 커지므로 비싼 패키지일수록 항상 이득이다.
작은 패키지를 여러 개 사는 것도 큰 패키지보다 손해다. 예: 5,500원 × 2 = 1,210코인 < 11,000원 1,265코인.

## 무료 획득

- 출석: 하루 2코인, 7일 연속 출석 보너스 5코인 (7일 합계 19코인)
- 챌린지 시즌 보상: 1위 30, 2위 20, 3위 10코인 (시즌 = 한 달, 시즌 최고 기록 기준. 화면에는 이미 표시되고, 실제 지급은 코인 시스템을 만들 때)

## 아이템 가격 (원화 표시 → 코인 환산, 10원 = 1코인)

- 테두리·패턴: 2,200원 → 220코인
- 테마: 3,300원 → 330코인
- 멤버십 30일: 3,300원 → 330코인

## 구현 메모

- 잔액은 클라이언트에서 쓰면 위조될 수 있으므로 서버(Cloud Functions, Blaze 요금제)에서만 바꾼다. 결제는 토스페이먼츠 + Cloud Functions로 승인한다.
- 출석과 챌린지 보상도 서버 함수에서 지급한다. 시즌 보상은 매달 1일 예약 함수로 지난 시즌 1~3위에게 지급한다.

## 1단계 구현 (2026-10-03, 서버 없이 — 라이브)

- `wallets/{uid}` {coins, items, membershipUntil, attendDay, streak, lastBuy}. 한 번 쓸 때 한 가지 동작만 허용하고 보안 규칙이 다시 계산한다: 출석(서버 시각 기준 KST 날짜), 유료 아이템 1개 구매(고정 가격, `paidItems()`), 멤버십 30일, 개발자 지급(1회 최대 100코인).
- 코인 표시: 시작 화면·수집품 오른쪽 위. 누르면 내 코인 창(출석 연속일, 멤버십 기간, 충전은 "곧 열려요").
- 수집품: 유료 아이템 가격표(코인)를 누르면 구매, 멤버 전용 아이템은 "👑 멤버십" 가격표로 멤버십 구매.
- 챌린지 시즌 보상: 개발자 계정의 챌린지 화면에 "🎁 지난 시즌 보상 지급" 버튼. `seasonRewards/{season}` 장부로 시즌당 한 번만 지급.
- 실제 돈 충전(토스 + Cloud Functions, Blaze 필요)은 2단계.
- 테스트 흔적: 개발자 계정 지갑에 테스트로 코인 지급·오닉스 구매·멤버십(11월 2일까지)이 남아 있음(개발자는 원래 전부 보유라 영향 없음).
