상태: **전 섹션 확정** (첫 출시 유료 아이템 목록 2026-10-03 확정, 섹션 5).

|---|---|---|

## 섹션 1 — 로그인과 데이터 (확정)

- **구글 로그인 필수.** 로그인 전에는 게임 진입 불가. 첫 로그인 때 닉네임 설정(구글 이름 기본값).
- **Firebase Auth(Google provider)** 사용. 지금의 Firebase 프로젝트 `straight-game` 그대로.
- **`users/{uid}`**: 통계·해금·장착·설정. 본인만 읽기/쓰기. 판 종료 시와 꾸미기 변경 시에만 저장(쓰기 횟수 절약). localStorage는 계정별 캐시로만.
- **개발자 계정**(아래 `devAccounts`)은 모든 유료·무료·멤버 아이템 사용 가능 + VIP 배지 + 그랜드마스터(섹션 3).
- **`entitlements/{uid}`**: 본인은 읽기만, 쓰기는 콘솔(운영자)·추후 서버만.
  - `items: [...]` → 구매한 영구 아이템 id
  - `membershipUntil` → 멤버십 만료 시각
- **기존 진행도 이관 없음.** 계정 데이터가 유일한 기준. "기존 플레이어는 전부 해금" 규칙 제거.
- **카카오톡 등 인앱 브라우저**는 구글 로그인이 막히므로 감지해 "Chrome/Safari로 열기" 안내.
- **온라인 방 규칙**을 "로그인한 사용자만"으로 강화.
- **특수 계정 지정 = Gmail 주소 기준.** 콘솔에서 `devAccounts/{gmail주소}` 문서에 `role` 필드를 넣으면 그 계정은 로그인 즉시 적용(로그인 전에도 미리 지정 가능, 여러 개 가능, 문서 삭제로 해제). 보안 규칙: `request.auth.token.email == 문서ID && request.auth.token.email_verified`일 때만 읽기 허용, 쓰기는 전부 금지(콘솔만). 코드에 이메일을 넣지 않는다. `entitlements/{uid}.role`은 사용하지 않는다.
  - `role: "dev"` (개발자): 모든 업적·유료·멤버 아이템 해금 + VIP 배지 + 그랜드마스터 + **개발 권한**(밸런스 데이터 `balanceLogs` 읽기 등).
  - `role: "tester"` (테스터): 게임 기능 테스트용. 모든 업적 해금(→ 그랜드마스터) + 모든 유료·멤버 아이템 사용 + VIP 배지. **개발 권한 없음**(`balanceLogs` 읽기 불가).
  - 지정할 계정: `emalration2@gmail.com` = dev, `dlatnwls0624@gmail.com` = tester.
- 콘솔 작업: Google 로그인 제공자 사용 설정, 승인 도메인에 `emalration2-sketch.github.io` 추가, 보안 규칙 게시, `devAccounts/{개발자 Gmail}` 문서 생성.
- 한계: 통계는 클라이언트가 기록하므로 업적 진행도 위조는 막을 수 없다. 유료 권한은 서버만 쓸 수 있어 안전하다.

## 섹션 2 — 부분 유료화 (확정)

**원칙**: 게임 플레이 100% 무료. 유료는 꾸미기뿐. 기존 업적 보상은 계속 무료.

| 상품 | 가격 | 방식 |
|---|---|---|
| 유료 테두리 | 개당 2,200원 | 영구 |
| 유료 패턴 | 개당 2,200원 | 영구 |
| 유료 테마 | 개당 3,300원 | 영구 |
| 멤버십 | 3,300원 / 30일 | 기간제, 기간 중 재구매 시 남은 기간 + 30일 |

- 칭호·BGM·캐릭터는 개별 판매하지 않는다.
- **멤버십 혜택**: (1) 판매 중인 모든 유료 아이템 사용, (2) 멤버십 전용 테마와 멤버십 전용 캐릭터, (3) 닉네임 태그 옆 VIP 배지.
- 멤버십 전용 테마는 **내 화면에만** 적용(다른 플레이어에게 강제하지 않음).
- **멤버십 만료 시** 멤버십으로 쓰던 아이템(유료·멤버 전용)은 기본 아이템으로 자동 해제.
- **구매 위치**: 수집품 각 탭에 유료 아이템을 가격과 함께 표시하고 거기서 구매.
- **결제는 후속 단계**: 토스페이먼츠/포트원 + Cloud Functions(Blaze 요금제) 결제 검증 → `entitlements` 기록. 사업자등록·통신판매업 신고·이용약관·개인정보처리방침·환불 정책(디지털 콘텐츠 청약철회 제한 고지)·미성년자 결제 안내 필요.

**이미 구현된 것** (커밋 `6384994`): 멤버십 전용 테마 3종(그린 펠트·월넛 테이블·블랙 마블), 수집품 "테마" 탭, VIP 배지. `hasMembership()`은 로그인 전까지 로컬 개발 서버에서만 true인 임시 판정.

## 섹션 3 — 업적 전체 클리어 최종 보상: 그랜드마스터 (확정)

**원칙**: 돈으로 살 수 없고 멤버십에도 포함되지 않는 명예 보상.

- **조건**: `UNLOCK_MILESTONES`의 업적을 **전부** 달성. 유료·멤버 아이템은 조건에 들어가지 않는다. 개발자 계정(`devAccounts`에 등록된 Gmail)은 조건과 상관없이 그랜드마스터로 취급.
- **보상 세트** (세 아이템 이름 모두 "그랜드마스터"로 통일)
  - 칭호 **그랜드마스터**: 업적 칭호 중 최상위
  - 테두리 **그랜드마스터**: 금색 테두리 위로 빛줄기가 주기적으로 한 번 지나가는 연출(번지는 발광 효과는 쓰지 않음)
  - 카드 패턴 **그랜드마스터**: 금박 반사 + 금색 결
  - 별도 MASTER 배지는 두지 않는다(칭호가 이미 "그랜드마스터"를 표시).
- **존재감 알림**: 게임이 시작될 때(혼자하기·온라인 모두) 그랜드마스터인 플레이어마다 채팅(로그)에 한 줄 표시.
  예: `🏆 그랜드마스터 {닉네임}님이 함께합니다!`
- **데이터**: 플레이어 객체에 `master: true`를 실어 다른 클라이언트에 전달. 방 데이터 정리(sanitize) 단계에서 boolean으로 강제.
- **수집품 표시**: 그랜드마스터 아이템 3종은 각 탭에 "모든 업적 달성 (n/N)" 진행도로 표시.
- **위험(감수)**: 통계가 클라이언트 기록이라 그랜드마스터 달성(세트·로그 알림) 위조가 가능. 결제 서버(Cloud Functions)를 붙일 때 서버 검증을 함께 도입.

## 섹션 4 — 숨은 기록과 밸런스 데이터 (확정, 로그인 작업과 함께 구현)

화면에는 보이지 않지만 나중에 랭크전·레벨·밸런스 조정에 쓰기 위해 쌓아 둔다.

- **계정 전적**: `users/{uid}.record = { wins, losses, draws, games }` (승률은 계산값이라 저장하지 않음). 혼자하기/온라인을 나눠 `record.solo`·`record.online`으로도 기록. 판이 끝날 때 갱신. 게임 화면에는 표시하지 않는다.
- **밸런스 데이터**: 판이 끝날 때마다 익명 집계 문서 1개를 `balanceLogs/{자동ID}`에 추가.
  - 담는 값: 인원수, 혼자/온라인, AI 난이도, 선공 자리, 승자 자리(또는 무승부), 총 턴 수, 조커 사용 수, 리셋(폭탄) 카드 사용 수, 바닥 자동 리셋 횟수, 승리 스트레이트(색·시작 숫자), 날짜.
  - 개인 식별 정보(uid·닉네임·이메일)는 넣지 않는다.
  - 보안 규칙: 로그인한 사용자는 **추가만** 가능(수정·삭제·읽기 불가). **읽기는 `role:"dev"` 계정만**(테스터 제외). 개발자는 콘솔이나 개발자 전용 화면에서 확인.
- 개발자 전용 통계 화면(선공 승률, 평균 턴 등)은 필요해질 때 따로 만든다.

## 섹션 5 — 첫 출시 유료 아이템 (2026-10-03 확정)

방향: **고급·프리미엄** — 업적 보상과 한눈에 구분되는 질감(금속·보석·네온·유리).

| 종류 | 가격 | 아이템 |
|---|---|---|
| 테두리 (4) | 2,200원 | 네온, 크롬, 오팔, 블랙골드 |
| 패턴 (4) | 2,200원 | 오닉스, 카본, 스테인드글라스, 크리스탈 |
| 테마 (2) | 3,300원 | 네온 아케이드, 오션 딥 |
| 멤버 전용 캐릭터 (2) | 멤버십 | 🦄 유니콘, 🐼 판다 킹 |

- 이름 충돌 회피: 패턴 "마블"은 테마 "블랙 마블"과, "별빛"은 테두리 "별자리"와 헷갈려 오닉스·크리스탈로 정함.
- 유료 아이템은 그랜드마스터 조건(업적)에 포함되지 않는다. 멤버십이면 전부 사용, 개발자·테스터 계정도 전부 사용.
- 결제 전까지는 수집품에 가격과 함께 잠금으로 표시(구매 버튼은 결제 단계에서).
