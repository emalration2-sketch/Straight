## 그랜드마스터 세트 (변경)

- 조건: 모든 **업적** 달성(이벤트·유료·멤버 아이템 제외). 업적 수 = 캐릭터 8 + 패턴 8(판수 7 + 튜토리얼) + 칭호 11 + 테두리 7 = **34개**.
- 보상: 칭호 **그랜드마스터**, 테두리 **솔라리스**, 패턴 **로열**. 게임 시작 시 채팅 알림 유지.

## 구현 메모

- 업적 ID 충돌: 100승이 캐릭터(고양이 예언자)·칭호(승부사) 둘 다 → 업적 ID를 보상 종류까지 포함하도록(예: `win:100:avatar`, `win:100:title`). 로그인 도입과 함께 진행도가 새로 시작되므로 기존 해금 기록 이관은 불필요.
- 새 통계: 색깔별 승리 수(`winsByColor`), 폭탄 카드 사용 수(`bombsUsed`), 최대 연승은 기존 `winStreak` 사용.
- 이벤트 획득 아이템: `event:true` 표시, 수집품에 "이벤트 획득" 표기, 지금은 잠금.
- 저장된 장착값 이동: 체리 테마 → 기본 테마, 삭제된 칭호(손이 큰 편·카드 산책러) → 해제, 기존 로열 패턴 → 기본 패턴.
- 하트 테두리 새 디자인, 렉스 버서커 아이콘, 벚꽃·눈송이 패턴, 에메랄드·루비 테두리 디자인 필요.
