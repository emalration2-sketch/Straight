# 코인 경제 (2026-10-03, 제안 단계 — 구현은 결제 작업과 함께)

재화 이름 **코인**. 아이콘은 금화(C1)에 "S" 대신 프리즘(`COIN_SVG`, 챌린지 보상 표시에 이미 사용 중).
멤버십은 **코인으로만** 구매한다. 무료로 코인을 얻는 곳은 출석과 챌린지 두 곳뿐이다.

## 충전 패키지 (기준: 1,100원 = 110코인, 10원 = 1코인)

| 가격 | 코인 | 기준 대비 보너스 | 비고 |
|---|---|---|---|
| 1,100원 | 110 | 0% | 사용자 확정 |
| 3,300원 | 350 | +6% | 사용자 확정 |
| 5,500원 | 610 | +11% | 제안: 600에서 상향, 단계마다 보너스가 커지게 |
| 11,000원 | 1,320 | +20% | 제안: 1,300에서 상향 |
| 33,000원 | 4,300 | +30% | 제안: 신규 고액 패키지 |
| 55,000원 | 7,700 | +40% | 제안: 신규 고액 패키지 |

보너스율은 0 → 6 → 11 → 20 → 30 → 40%로 단계마다 커진다. 사용자가 처음 제시한 600·1,300을 그대로 쓰면 보너스율이 +9%, +18%가 된다.

## 무료 획득

- 출석: 하루 2코인, 7일 연속 출석 보너스 5코인 (7일 합계 19코인)
- 챌린지 시즌 보상: 1위 30, 2위 20, 3위 10코인 (시즌 = 한 달, 시즌 최고 기록 기준. 화면에는 이미 표시되고, 실제 지급은 코인 시스템을 만들 때)

## 아이템 가격 (원화 표시 → 코인 환산, 10원 = 1코인)

- 테두리·패턴: 2,200원 → 220코인
- 테마: 3,300원 → 330코인
- 멤버십 30일: 3,300원 → 330코인

## 구현 메모

- 잔액은 클라이언트에서 쓰면 위조될 수 있으므로 서버(Cloud Functions, Blaze 요금제)에서만 바꾼다. 결제는 토스페이먼츠 + Cloud Functions로 승인한다.
- 출석과 챌린지 보상도 서버 함수에서 지급한다. 시즌 보상은 매달 1일 예약 함수로 지난 시즌 1~3위에게 지급한다.
