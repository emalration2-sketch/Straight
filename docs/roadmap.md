# 스트레이트! 개발 로드맵

목적: 게임성 강화 — 특히 "상대와의 상호작용 부족"을 해결하고 재방문 동기를 만든다.
마지막 갱신: 2026-10-02

## 진행 중

- **구글 로그인 · 부분 유료화 · 그랜드마스터 · 숨은 기록/밸런스 데이터**
  스펙: `docs/superpowers/specs/2026-10-02-account-monetization-design.md`

## 확정 (다음 순서)

1. **상대 진행도 표시 + 직전 선언**
   - 상대 칸에 가장 긴 스트레이트 진행도(예: 핑크 3/5)를 작게 표시.
   - 누군가 4/5가 되면 로그·효과음으로 자동 선언 → 견제 플레이 유도.
   - 선언 문구: **"레디!"** — 예: `🔥 수달 레디! (핑크 4/5)`
2. **데일리 챌린지**: 매일 모두에게 같은 카드 배치, 최소 턴으로 스트레이트 완성 경쟁 + 순위표. (로그인 필요)
3. **온라인 편의 기능**: 같은 멤버로 바로 다시 하기, 빠른 매칭, 끊긴 사람 재접속.

## 향후 계획

- **랭크전**: 실력 점수(ELO 계열)로 오르내리는 경쟁 등급, 시즌제·시즌 보상(꾸미기).
- **레벨 시스템**: 플레이할수록 쌓이는 경험치 기반 성장 지표. 내려가지 않는다.
  - 레벨 ≠ 랭크: 레벨은 "얼마나 많이 했나"(누적·단조 증가), 랭크는 "얼마나 잘하나"(승패로 오르내림·시즌 초기화).
- 위 두 기능의 재료가 되는 계정 전적(승/패/무승부/판수)은 로그인 작업 때부터 숨은 기록으로 쌓는다.
